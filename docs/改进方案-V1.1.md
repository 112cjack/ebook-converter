# 改进方案 V1.1（第一批）

项目：电子书转换器 ｜ 日期：2026-10-31 ｜ 编制：112cjack
依据：用户使用反馈（2026-10-31）与产品评审，延续《电子书转换器技术方案》V1.0 的「保持轻量、复用优先」原则。第二批项（上传进度条、打开单个输出文件、完成提醒、拖文件夹提示、waitress、多格式导出、高级转换参数）列入路线图，不在本方案范围。

## 1 背景

用户实测 exe 后反馈三类问题：① Calibre 未安装时的引导不够主动、检测结果不显眼；② 输出目录体验不直观（默认位置不可见、网页拿不到源文件路径）；③ 同格式转换（azw→azw）无意义但照常执行。评审另发现健壮性缺口：转换中的任务不可取消、超长文件名可能转换失败、临时文件清理不可靠、失败详情未展示、无应用日志。用户同时确认：引擎采用**官方便携版**（功能与标准版一致，体积相当，但可解压到程序目录随程序走，官方支持命令行无人值守安装——见 calibre-ebook.com/download_portable）。

## 2 引擎与安装引导（A 组）

- **A1 引导自动弹出**：页面加载后若引擎未就绪，自动弹出安装引导对话框（保留顶部引导条与右上角胶囊）。
- **A2 便携版引擎方案**（替代原「仅 winget 引导」）：
  - 探测顺序调整为：程序目录 `engines\calibre\`（含其一级子目录，兼容便携版解压结构）> 设置手动路径 > PATH 与常见安装位置。
  - 引导对话框提供两个动作：**① 下载便携版引擎**（默认）：服务端下载官方便携版安装器到临时目录，以 `calibre-portable-installer.exe "<程序目录>\engines\calibre"` 无人值守解压，完成后自动重新检测；**② winget 安装标准版**（备选）：`winget install --id calibre.calibre -e --accept-source-agreements --accept-package-agreements`。winget 不可用时仅显示 ① 与官网手动下载。
  - 安装在后台线程执行，安装期间 `/api/status` 的 `engine` 字段携带 `installing` 与阶段文本（下载中 x% / 解压中 / 校验中），引导对话框轮询展示；完成后自动刷新状态。
  - 实施时验证项：官方便携版安装器的稳定下载 URL 与静默参数（以官方下载页为准）；安装到短路径（路径长度限制），程序目录过长时界面提示。
- **A3 检测结果醒目化**：页面加载后 toast 报告检测结论（含版本号）；引擎未就绪时「开始转换」按钮禁用并提示原因。
- **A4 启动入口**：打包产物改名「电子书转换器.exe」（实施时验证 PyInstaller 中文名，若有兼容问题回退英文名、仅快捷方式用中文名）；新增 `POST /api/create-shortcut`，由页面「创建桌面快捷方式」按钮触发，服务端经 PowerShell WScript.Shell 在用户桌面（`[Environment]::GetFolderPath('Desktop')`）生成指向 exe 的 .lnk，无新增依赖。

## 3 输出目录体验（B 组）

- **B1 目录浏览器**：新增 `GET /api/browse?path=...`——`path` 为空时返回本机盘符列表，否则返回该目录下的子目录列表与上级路径；仅列目录、过滤隐藏项；拒绝越界（非绝对路径直接 400）。前端弹对话框逐级选择，底部操作栏新增「选择输出目录」按钮，选定后本会话生效并随 convert 请求提交。
- **B2 输出目录显式化**：前端按「用户本次显式选定 > 会话内上次成功转换的目录」决定请求参数，后端按「请求参数 > 设置默认输出目录 > 程序目录 converted」兜底；操作栏常显「将输出到：xxx」。
- **B3 断连提示友好化**：前端 fetch 网络层失败统一翻译为「无法连接本地服务，程序可能已关闭，请重新打开程序并刷新本页面」，以页面顶部常驻提示条呈现（恢复后自动消失），替代瞬时 toast。

## 4 任务处理（C 组）

- **C1 同格式跳过**：`POST /api/convert` 创建任务时，若源格式与目标格式相同，直接建 `skipped` 任务（消息「源文件已是 X 格式，无需转换」），不入队。
- **C2 取消转换中的任务**：任务状态机新增 `cancelled`（已取消）。引擎层 `convert_file` 的流式路径新增可选 `cancel_check` 回调（每秒检查一次），返回 True 时终止子进程、清理残缺输出、返回失败（消息「已取消」）；worker 据此置 `cancelled`。CLI 路径与既有行为零变化。前端 converting 行加「取消」按钮。
- **C3 覆盖重转**：`POST /api/convert` 新增可选 `overwrite`（布尔）。为 True 时 worker 在转换前删除已存在的同名输出（批内重名判定保留）。前端为 done/skipped 行提供「重新转换」按钮（携带 overwrite）。
- **C4 扫描版 PDF 前置警告**：上传时即对 PDF 调用 `pdf_has_text_layer`，上传记录携带 `scanned_pdf` 标记，列表行显示「扫描版」角标；转换结果中的警告保留不变。
- **C5 失败详情展示**：失败行新增可展开的「查看详情」，展示后端已返回但前端未呈现的 `error_detail`。

## 5 健壮性（D 组）

- **D1 长文件名截断**：`safe_filename` 对主名截断（保留扩展名，总长控制在安全范围），截断发生时前端在对应行提示「文件名过长已截断」。
- **D2 启动时清理残留**：`create_app` 时清空并重建上传目录（测试模式除外），替代仅依赖 atexit 的清理策略（atexit 保留，双保险）。
- **D3 应用日志**：标准库 `logging` 输出到控制台，记录启动、端口绑定、引擎检测结论、任务开始/完成/失败/取消、安装进度；格式含时间与级别。不写文件（控制台窗口常驻）。

## 6 API 变更汇总

| 变更 | 内容 |
|---|---|
| 新增 | `GET /api/browse`、`POST /api/install-engine`、`POST /api/create-shortcut` |
| 扩展 | `POST /api/convert`（`overwrite` 参数、同格式自动跳过）、上传响应与任务视图（`scanned_pdf`）、`/api/status` 的 `engine`（`installing` 状态）、任务状态机（`cancelled`）、`convert_file`（`cancel_check` 参数） |
| 不变 | 其余接口签名与既有行为；引擎层公开接口向后兼容 |

## 7 测试计划

- 服务层（假引擎/假下载器/假 PowerShell）：browse 路径校验与盘符枚举、install-engine 状态流转、同格式跳过、overwrite 重转、取消流转、上传 PDF 预检测、长文件名截断、启动清残留、create-shortcut 调用校验。
- 引擎层：便携版目录探测、`cancel_check` 取消路径（超时轮询语义、残缺输出清理、返回值）。
- 手工验收：更新技术方案 8.2 路径——新增便携版引导安装、取消转换中任务、覆盖重转、同格式提示、断连提示复现（关闭程序窗口）。
- 全量 pytest 通过后按里程碑拆分 commit，同步增补 `docs/方案补记.md`。

## 8 风险与对策

| 风险 | 对策 |
|---|---|
| 便携版下载 URL / 静默参数与预期不符 | 实施时以官方下载页实测为准；失败时回退「官网手动下载」引导 |
| PyInstaller 中文产物名兼容问题 | 实测验证；不通过则回退英文名，快捷方式仍用中文名 |
| 取消与转换完成的竞态 | 取消判定在 worker 内串行处理；kill 后统一走既有失败清理路径 |
| 下载大文件（100+MB）体验 | 安装状态按阶段/百分比轮询展示；失败可重试 |
