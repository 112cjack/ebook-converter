安装 Calibre 转换引擎

本工具使用开源软件 Calibre 自带的 ebook-convert 执行转换，请先安装 Calibre：

winget install calibre.calibre

或到官网下载：calibre-ebook.com/download

安装完成后重启本程序即可自动检测；若 Calibre 安装在非默认位置，请在「设置」中手动指定 ebook-convert 路径。
